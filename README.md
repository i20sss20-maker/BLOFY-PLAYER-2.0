# BLOFY PLAYER — Android & Android TV Media Player

**Your playlists. Your screen.** / **بلوفي بلاير — قوائمك على شاشتك**

BLOFY PLAYER is a media player for **Android and compatible Android TV devices**. It helps you play and organize your own authorized **M3U playlists** and **Xtream Codes** sources, including live TV, movies, series, favorites and search features supplied by your own source.

> **Important:** BLOFY PLAYER does **not** provide, sell, host or distribute TV channels, movies, series, media playlists or content subscriptions. Use only sources you are authorized to access. App activation is separate from any media subscription.

### Install & get started

1. **Android / Android TV:** check the official [Google Play listing](https://play.google.com/store/apps/details?id=tv.blofy.player.v2) for device and region compatibility.
2. **Alternative Android APK:** use the [official download center](https://blofyplayer.com/downloads). On a compatible Android TV box, the short address is **blofyplayer.com/apk**.
3. **Open the app:** follow the device-linking instructions, then add only playlists or credentials from sources you are authorized to use.

**Do not install APK files from unofficial mirror sites.** Installing a new version over an existing installation normally preserves app data; don't remove the current app solely to update.

### حول التطبيق

**بلوفي بلاير** مشغل وسائط لأجهزة أندرويد والتلفزيون المتوافق مع Android TV، يدعم قوائم **M3U** وبيانات **Xtream Codes** التي يضيفها المستخدم. يتيح تصفح القنوات والأفلام والمسلسلات والبحث والمفضلة بحسب المصادر المصرّح باستخدامها. **التطبيق لا يوفّر قنوات أو اشتراكات أو محتوى بث.**

للتثبيت ابدأ من [Google Play](https://play.google.com/store/apps/details?id=tv.blofy.player.v2)، أو استخدم [صفحة APK الرسمية](https://blofyplayer.com/downloads)، ثم راجع [دليل التثبيت](https://blofyplayer.com/guide).
