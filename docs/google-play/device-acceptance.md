# قبول النسخة التجارية على أجهزة فعلية

تُنفذ هذه الحالات على جهاز اختبار وبيانات اختبار مصرح بها، مع حفظ نسخة البيانات قبل اختبارات التثبيت.
لا تُحذف بيانات جهاز العميل المدفوع للاختبار. نفّذ استعادة الرخصة على جهاز اختبار بعد حفظ رمز الاستعادة والتأكد من أن إبطال الجهاز السابق مقصود.

| الحالة | الدليل المطلوب |
|---|---|
| هاتف Honor ومستقبل Android TV | طراز الجهاز وإصدار Android ونسخة التطبيق ونتيجة كل حالة |
| دخول أول مرة وتبديل القائمة | تظهر القائمة المختارة فقط؛ لا استيراد تلقائي من الموقع؛ الرجوع وإلغاء التحميل يستجيبان |
| فقد الإنترنت أثناء التحقق من الدخول | انتهاء الانتظار برسالة مفهومة دون إغلاق التطبيق أو مسح القوائم |
| تحديث قوائم من الموقع | الإضافة والتعديل والحذف المصرّح بها تنعكس على الجهاز الصحيح وحده |
| رجوع وخروج وإعادة فتح | تأكيد الخروج يعمل والمفضلة والاستئناف تبقى |
| تصفح كتالوج كبير | قياس زمن أول عرض وفتح الفئات والبحث بالريموت؛ لا توقف أو إعادة تحميل كاملة عند كل رجوع |
| بث مباشر 30 دقيقة وتنقل بين قنوات | قياس زمن أول إطار والتوقفات والأخطاء؛ مصدر مصرح به وسجل الشبكة المستخدم |
| فيلم وحلقات وترجمة وصوت واستئناف | رقم الحلقة وموضع الاستئناف وخيار المسار يبقى صحيحًا عند العودة والخلفية |
| تفعيل تجربة منتهية ورخصة مدفوعة وحظر جهاز | حالة الخادم تنعكس ضمن سياسة مهلة معلنة؛ اختبار رمز جلسة قديم بعد الحظر مطلوب قبل ادعاء الإبطال |
| تحديث موقع إلى الإصدار النهائي وتحديث Play | تثبيت موضعي بنفس الحزمة وشهادة متوافقة دون فقد الهوية والقوائم |
| Play على جهاز 16 KB | تشغيل التطبيق وملفات split المبنية من AAB؛ فحص ELF وحده غير كافٍ |
| خصوصية ودعم وحذف ورخصة | كل رابط يفتح صفحة صحيحة، ولا تُعرض ميزة تجارية غير متاحة أو خطط لا تعمل |

إذا حدث الكراش المتقطع، تحفظ لحظته وخطوات تكراره وسجل `adb logcat -b crash -d` من جهاز الاختبار.
تُراجع السجلات وتُنقّح من بيانات الاشتراك قبل مشاركتها؛ لا ترسل رمز ربط الجهاز أو كلمات المرور.
لا تُعتبر نتائج المحاكي قياسًا لسرعة مستقبل العميل أو جودة سيرفره.
