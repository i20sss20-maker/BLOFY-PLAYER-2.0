# جرد البيانات قبل تعبئة Data safety

هذا جرد مستخرج من الكود، وليس إقرار Data safety جاهزًا للإرسال. لا تختَر «لا يجمع أي بيانات».

| البيانات | أين تُعالج؟ | الغرض والملاحظة |
|---|---|---|
| معرّف التثبيت ورمز ربط الجهاز وحالة التفعيل وإصدار التطبيق | التطبيق وخادم BLOFY | المصادقة والرخصة والتجربة؛ الخادم يخزن إثبات HMAC للرمز، وقد تحتفظ قاعدة قديمة برموز تحتاج ترحيلًا |
| روابط مزود المحتوى واسم المستخدم وكلمة المرور ورمز المشترك | الجهاز، مزود المستخدم، والخادم عند استعمال بوابة القوائم/المشتركين | تشغيل المصادر وإدارة القوائم. AES-GCM للخادم وAndroid Keystore محليًا؛ يوجد fallback محلي غير مشفر يجب معالجته |
| بداية التشغيل وعدد التوقفات ورمز الخطأ ورسالة منقحة ونوع المحتوى ومعرّف مزود مشتق | التشخيص المحلي وخادم BLOFY | قياس الأعطال والأداء؛ الإرسال الحالي تلقائي ولا توجد موافقة منفصلة في هذا المسار |
| الملفات الشخصية والمفضلة والاستئناف | قاعدة بيانات الجهاز | وظائف المستخدم. كود المزامنة موجود لكن مسار خدمة cloud في الإنتاج يرجع 404 وقت الفحص |
| عنوان IP وسجلات الطلبات وبيانات الدعم التي يُدخلها العميل | الاستضافة وخادم BLOFY | الأمن وتشغيل الخدمة والدعم؛ يلزم تأكيد مدد الاحتفاظ ومزودي المعالجة الفعليين |

لا توجد طلبات صلاحيات كاميرا أو ميكروفون أو جهات اتصال أو موقع جغرافي أو READ_PHONE_STATE في badging للـAPK المفحوص.
المعرّف الحالي عشوائي لكل تثبيت ولا يُشتق من ANDROID_ID. عدم وجود إذن لا يُغني عن مراجعة SDKs وبيانات شبكاتها.

## الخصوصية والحذف

السياسة النهائية يجب أن تسمي BLOFY PLAYER والجهة المسؤولة، وتضع جهة اتصال صحيحة، وتشرح البيانات والغرض
والجهات المعالجة ومدد الاحتفاظ وطرق طلب الحذف والتعامل مع النسخ الاحتياطية والاسترداد. هذه المعلومات لم تُختلق في المسودة.
حذف قائمة تشغيل يزيل تلك القائمة فقط؛ تعطيل جهاز لا يحذف بياناته. حذف التطبيق لا يمسح بيانات الخادم تلقائيًا.
ينبغي أن يظل طلب الحذف ممكنًا بعد انتهاء التجربة، وأن تشمل الاستجابة بيانات القوائم والتشخيص والدعم المرتبطة
مع الإفصاح عن أي احتفاظ مشروع؛ لا يُنشأ endpoint حذف دون مصادقة وتأكيد واضحين.

بيانات الدخول تُعد حساسة. دعم HTTP لمزود المستخدم يمنع الجزم بتشفير النقل لجميع المسارات؛ التحذير وحده
لا يثبت موافقة Google على المسار. يجب حسم سياسة HTTPS لنسخة المتجر مع مراعاة توافق السيرفرات.
ولا نفترض أن «معرّف جهاز» يعفي تلقائيًا من تعريف الحساب، لأن البوابة توفر به مصادقة وبيانات مستمرة.

المصدر: [سياسة بيانات المستخدم](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en)،
[تعريف الحساب والحذف](https://support.google.com/googleplay/android-developer/answer/13327111).
