# BLOFY STREAM isolated web preview: origin EOF resilience and anonymous source health

Scope: Railway preview `blofy-stream-native-web-parity` and its existing isolated `blofy-stream-web-vod-seek-pilot` worker ONLY. This is not a customer Android release and PR #804 stays draft.

Features: (1) a credential-isolated, HMAC-keyed, capped and expiring 1.6–30s source-origin cooldown when the original feed repeatedly finishes prematurely, its live manifest stalls, or FFmpeg crashes; (2) a numeric Retry-After for temporary HTTP 503 origin cooldown, forwarded through the authenticated web proxy without source URLs/credentials; (3) bounded delayed Hls.js retries for temporary 502/503/504, cleared when fragments resume or the channel changes; (4) read-only, aggregate 2-minute live-source disruption counts in Settings -> اتصالات البث ومشاركة المصدر, showing only small numbers, no account identities.
